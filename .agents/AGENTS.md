# Catan CV Service Rules

## Domain Invariants (Digital Screenshots)
- **Input Media**: Inputs are digital screenshots of web Catan games (e.g., Colonist.io).
- **Geometric Invariance**: All board elements, hex tiles, number tokens, and harbor icons are strictly 2D axis-aligned (0° rotation, zero perspective tilt).
- **Color Invariance**: Terrain tiles, ocean canvas (`#0966a4`), and harbor icons use consistent flat digital RGB hex color signatures.
